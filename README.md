# 📝 Smart To-Do List

A simple and interactive **Smart To-Do List application built with Python**.
This project allows users to manage daily tasks directly from the terminal.

## 🚀 Features

* ➕ Add new tasks
* 📋 View all tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 🔍 Search tasks using keywords
* 📊 View task statistics
* 🚪 Exit the application
* 🔄 Menu-driven interactive interface

## 🛠️ Technologies Used

* **Python 3**
* Lists
* Dictionaries
* Loops
* Conditional statements
* Functions/operations
* String handling
* User input

## 💻 How It Works

When the program starts, it displays a menu:

```text
==============================
       SMART TO-DO LIST
==============================
1. Add Task
2. View Tasks
3. Delete Task
4. Mark Task Completed
5. Search Task
6. Task Statistics
7. Exit
```

### Add Task

Select `1` and enter your task.

```text
Enter your choice: 1
Enter your task: Complete Python project
Task added successfully!
```

### View Tasks

Select `2` to display all saved tasks along with their status.

```text
--------- MY TASKS ---------
1 . Complete Python project [ Pending ]
```

### Delete Task

Select `3`, choose the task number, and the task will be removed.

### Mark Task Completed

Select `4` and choose a task number. Its status changes from:

```text
Pending
```

to:

```text
Completed
```

### Search Task

Select `5` and enter a keyword
